# 🎵 Music Player App

A simple, responsive music player built with **HTML**, **CSS**, and **JavaScript**.  
It lets you browse music folders, load playlists dynamically, and control playback with an easy-to-use interface.

---

## ✨ **Features**

✅ Play audio files in the browser  
✅ Dynamic playlist loading — songs are loaded when you click on a folder  
✅ Clean and responsive music controller with **Play**, **Pause**, **Next**, **Previous**  
✅ Simple folder structure for easy music management
